# bili-dy-down 功能增强 SPEC
基线：master 07e1dd4ebef7a3b40995d3f6f369e671e96eb70d。目标：个人 Windows 轻量视频素材采集工具，优先抖音与 B站。

## 范围
- P0：B站单视频/批量链接原功能不退化；作者主页、投稿列表、分页、选择下载、失败提示、去重。
- P1：合集/系列、公开收藏夹；恢复手动主页采集，与现有订阅分离；跨平台批量链接。
- P2：目录规则、历史、元数据导出、对外 API；B站订阅纳入本期；TikTok 适配延期，不纳入本期验收。
- 非目标：大型数据平台、多租户、自动绕过访问控制、替换下载器、强制登录。

## 用户故事
输入 space.bilibili.com/<mid> 或投稿页，选择最近 N 条或逐页加载，预览封面/标题/作者/时长/时间/播放量，筛选、勾选、选择分P和现有画质策略，提交统一下载队列；失败可重试，已下载可识别。手动抓取不创建订阅。

## 边界
真实投稿接口可能需要有效 Cookie 或遇到风控；明确提示登录失效、限流、无权限，不把错误当空列表。全部作品指可访问的投稿，不承诺私密/删除作品或所有画质。先获取列表，再按选中项解析详情，下载前刷新播放流。

## 强制开发约束
仅在 codex-dev 增量开发；保留 Tauri 2、React/TypeScript、FastAPI、SQLite 和现有主题、悬浮导航、Hero、下载队列。不得擅自重构 UI、替换技术栈或引入 Redis、PostgreSQL、Docker 等额外运行依赖。保持 Windows 原生打包、原有接口和数据兼容；凭据不得进入日志、提交或导出。仅处理有权访问及下载的内容。

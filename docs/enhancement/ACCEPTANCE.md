# 验收与回归
## P0 验收清单（初始全部待验证）
- [ ] Windows 原安装包/开发启动正常，原四个导航与主题保持。
- [ ] 单个BV/AV/短链、批量B站链接、抖音视频/图文解析下载正常。
- [ ] B站主页及投稿链接识别，MID 校验，合法 Cookie 和匿名分别实测。
- [ ] 获取 1/30/50/100 条，空主页与错误区别，显示真实总数。
- [ ] 选择作品后获取真实 cid 和分P，单P/多P下载及 DASH 合并成功；失败项不产生无效任务。
- [ ] 主页切换、重复 BV、取消/迟到响应、网络错误、Cookie 失效、限流有明确行为。
- [ ] Phase 2：超过100条可继续分页，不重复第一页，最后一页、重复页、筛选及重试正确。
- [ ] 下载队列、SQLite 旧数据、订阅、Cookie 加密、设置不退化。
- [ ] pytest 现有及新增测试、前端项目既有 lint/typecheck/build、Windows Tauri 安装包构建与安装实测。
## 记录规范
每项记录 commit、环境、命令、结果、失败证据；模拟测试不等于真实平台测试。当前尚未执行真实接口、Windows 客户端或构建测试。使用有权下载的视频，避免凭据进入测试输出。

## 强制开发约束
仅在 codex-dev 增量开发；保留 Tauri 2、React/TypeScript、FastAPI、SQLite 和现有主题、悬浮导航、Hero、下载队列。不得擅自重构 UI、替换技术栈或引入 Redis、PostgreSQL、Docker 等额外运行依赖。保持 Windows 原生打包、原有接口和数据兼容；凭据不得进入日志、提交或导出。仅处理有权访问及下载的内容。

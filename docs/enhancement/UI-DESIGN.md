# 桌面 UI 增量设计
## 保留
FloatingDock 四入口、App 路由、窗口标题栏、紫色/毛玻璃主题、明暗主题、HeroSection/HeroActions/HeroTextarea/ParseButton、现有列表及底部工具栏。实际运行截图作为视觉验收基准；当前文档依据源码，尚未截图验证。

## B站抓取页
Hero 内部增加 视频链接 / UP主主页 两模式；后续追加 合集/系列 / 收藏夹。默认视频链接，保留原输入/导入/Cookie。主页模式输入主页或 MID，选择数量和排序（分页增强后支持更多），解析后复用列表；显示加载数/总数、加载更多、重试；摘要没有 pages 时不能直接用 cid=0 下载，先补齐详情并允许选择分P。底部保持全选、清空、开始下载。选择状态使用稳定ID，过滤不隐式选中新结果。

## 主页抓取页
新增 手动抓取 / 订阅管理 二级切换，订阅面板原样保留。手动支持抖音/B站识别；共享作品列表，不新增一级导航。B站入口可复用同一采集组件。批量抓取页第一阶段不变，后续支持混合链接并标识平台。

## 状态
空态、加载、部分成功、无作品、Cookie失效、限流、网络失败分别展示；错误不中断已加载列表。下载前显示失败详情与可下载数量。窄窗口可滚动，键盘可操作，深浅色主题一致。

## 强制开发约束
仅在 codex-dev 增量开发；保留 Tauri 2、React/TypeScript、FastAPI、SQLite 和现有主题、悬浮导航、Hero、下载队列。不得擅自重构 UI、替换技术栈或引入 Redis、PostgreSQL、Docker 等额外运行依赖。保持 Windows 原生打包、原有接口和数据兼容；凭据不得进入日志、提交或导出。仅处理有权访问及下载的内容。
